claude-code-sandbox

このアプリは、開発者本人が自分の Google アカウントのデータを扱うための個人用ツールです。一般には提供していません。

プライバシーポリシー

扱うデータ

開発者本人の Gmail のメールと、メールの設定（ラベル・フィルタ）です。本人以外のアカウントのデータは扱いません。

利用目的

本人のメールの確認・整理（検索、既読、ラベル付け、アーカイブ、フィルタの管理）を自動化するためだけに使います。

保存と共有

  • 認証情報は、本人が管理するクラウドの鍵保管庫（Azure Key Vault）に保存します。
  • メールの内容を第三者に販売・提供することはありません。広告にも使いません。
  • 処理の一部に AI アシスタント（Anthropic の Claude）を使い、本人への報告を作るためにメールの一部を渡すことがあります。

Google API サービスのユーザーデータに関するポリシー

Google API から受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

アクセスの取り消し

Google アカウントのサードパーティ アクセスから、いつでもこのアプリのアクセスを取り消せます。
